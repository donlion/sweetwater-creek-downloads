# Sweetwater Creek for the Mac

The Mac app of [Sweetwater Creek](https://sweetwater-creek.vercel.app/), a calm town-builder set in the California pines in 1851.

Download *Sweetwater-Creek-mac.zip* from [the latest release](https://github.com/donlion/sweetwater-creek-downloads/releases/latest).

## Opening it the first time

Sweetwater Creek is an indie game, signed by its maker but not notarised by Apple, so the first time you open it macOS asks you to vouch for it. After that it opens like any other app.

1. **Unzip it.** Open your Downloads folder and double-click *Sweetwater-Creek-mac.zip* (Safari may have unzipped it for you).
2. **Put it in Applications.** Drag *Sweetwater Creek* into the Applications folder. (Forget, and it offers to move itself there when a new version comes.)
3. **Open it, and press Done.** macOS says it can’t check the game for malware and doesn’t open it. Press *Done*, not the button that throws it away.
4. **Open Anyway.** Open System Settings → Privacy & Security and scroll down to Security, where it says *“Sweetwater Creek” was blocked*. Press *Open Anyway*, then *Open Anyway* again, with your password or Touch ID.
5. **That’s all.** From now on it opens like any other app, and keeps itself up to date.

On macOS 12 or older, step 4 is under System Preferences → Security & Privacy → General. The button only shows for an hour or so after macOS stops the game: if it’s gone, open the game again.
