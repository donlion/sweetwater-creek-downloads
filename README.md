# Sweetwater Creek for the Mac

The Mac app of [Sweetwater Creek](https://sweetwater-creek.vercel.app/), a calm town-builder set in the California pines in 1851.

Download the newest from [the latest release](https://github.com/donlion/sweetwater-creek-downloads/releases/latest): unzip it and open Sweetwater Creek. The first time, macOS will not open it (it is not notarised by Apple): open System Settings → Privacy & Security, press *Open Anyway*, then open it again.
